# ARIA Visualizer 3D 🎵

כלי בדפדפן שהופך **תמונה + שיר** לסרטון תלת־ממדי לסושיאל (Reels / TikTok / Shorts / יוטיוב), בלי צילום פנים.

**קישור (אחרי הפעלת GitHub Pages):** https://ariadic.github.io/House-of-aria/

## מה מיוחד
- **תלת־ממד אמיתי מתמונה רגילה**: מודל AI (Depth Anything V2) מחשב את העומק בתמונה, והמצלמה נכנסת לתוכה. החישוב רץ בדפדפן, והמודל (כ־27MB) יורד רק בפעם הראשונה.
- **זיהוי ביט אמיתי**: קיק, סנר והיי־האט מזוהים בנפרד, וכל אחד מפעיל תגובה משלו. יש גם זיהוי דרופים וכיוון עוצמה אוטומטי לפי השיר.
- **איכות קולנועית**: בלום, סטייה כרומטית, קרני אור, דירוג צבע וחיתוכי מצלמה על הביט.
- **8 סגנונות מוכנים ו־61 אפקטים** שאפשר לשלב בחופשיות.

## שימוש
1. פותחים את הקישור או את `index.html` ב־Chrome או Edge. צריך חיבור לאינטרנט.
2. מעלים תמונה ושיר.
3. בוחרים סגנון, ומכווננים עוצמה, עומק ומהירות מצלמה.
4. בוחרים מקטע ופורמט, ולוחצים **ייצא סרטון**. הייצוא בזמן אמת, ונשמר כ־MP4 ב־Chrome/Edge.

כל העיבוד נעשה מקומית בדפדפן. התמונות והשירים לא נשלחים לשום שרת.

## כרטיס שיר 3D (`card.html`)
כרטיס שיר שמרחף בתלת־ממד (בסגנון פוסט של YouTube Music), עם ייצוא לסרטון.
- **טקסטים**: כותרת עליונה, שם השיר, שורת משנה ותווית. כל אחד נערך בנפרד.
- **פונטים מ־Google Fonts**: בחירה מרשימה או הקלדה של כל שם פונט, בנפרד לכותרת, לשם השיר ולטקסטים הקטנים.
- **צבעים**: בחירה ידנית, או חילוץ פלטה מתמונה והחלה אוטומטית או בלחיצה על צבע.
- **תנועה**: מהירות, סיבוב, הטיה, ריחוף, פרספקטיבה, גודל ותגובה למוזיקה.
- **ייצוא**: 9:16, 4:5, 1:1 או 16:9, עם בחירה של מקטע מהשיר. הקובץ יוצא כ־MP4 ב־Chrome או ב־Edge.
- **נייד**: התצוגה נשארת קבועה בראש המסך בזמן גלילה בהגדרות. אחרי הייצוא אפשר לשמור את הסרטון ישר לגלריה או לשתף לאינסטגרם. עובד ב־iPhone (Safari) וב־Android (Chrome).
