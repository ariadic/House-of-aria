# ARIA Visualizer 🎵

כלי בדפדפן שהופך **תמונה + שיר** לסרטון ויזואליזציה לסושיאל (Reels / TikTok / Shorts / יוטיוב), בלי צילום פנים.

## איך משתמשים
1. פותחים את `index.html` ב־**Chrome** או **Edge** (לחיצה כפולה על הקובץ, אין צורך בהתקנה).
2. מעלים תמונה (או גוררים אותה לתצוגה) ושיר (MP3/WAV/M4A, וגם קובץ וידאו שממנו ייקח את הסאונד).
3. בוחרים את המקטע: שעת התחלה וסיום, או "התחלה = עכשיו" תוך כדי האזנה. לחיצה על ציר הגל קופצת לנקודה.
4. בוחרים פורמט: 9:16, 4:5, 1:1 או 16:9.
5. בוחרים פריסט, או משלבים בחופשיות כל כמות מתוך **84 אפקטים**.
6. מוסיפים שם שיר/אמן, ולוחצים **ייצא סרטון**.

הייצוא נעשה בזמן אמת: מקטע של 30 שניות לוקח 30 שניות. חשוב להישאר בטאב עד הסוף.
ב־Chrome/Edge מעודכנים הקובץ יוצא כ־**MP4**. בדפדפנים אחרים הוא יוצא כ־WEBM.

## קבוצות האפקטים
- **תנועת תמונה (6)**: זום על הבס, דופק על ביט, רעידת מצלמה, נדנוד, קן ברנס, קפיצה
- **פילטרים לתמונה (8)**: שינוי גוון מוזיקלי, הבהרה על בס, צבע לפי עוצמה, פוקוס, קונטרסט, רקע מטושטש, וינטג׳, שחור-לבן
- **עיוותים ופלאשים (10)**: פיצול RGB, גליץ׳, פיקסלים, עיוות גלי, מראה, קליידוסקופ, מנהרה, הד רפאים, היפוך צבעים, פלאש
- **ספקטרום ועמודות (11)**: עמודות תחתונות, עמודות מראה, עמודות מעגליות, הרים, מטריצת נקודות, LED, מדי VU, ספקטרוגרמה, אש, עמודות בשוליים, קווי רכס
- **גלי קול (5)**: קלאסי, משולש ניאון, מעגלי, עמודות סימטרי, ליסאז׳ו
- **צורות ומעגלים (13)**: עטיפת אלבום עגולה ומרובעת, תקליט מסתובב, קרני שמש, ספירלה, מצולעים, בועה נוזלית, טבעות, גלי הדף, נקודות במסלול, מנדלה, משושים, מסגרת ניאון
- **חלקיקים ומזג אוויר (10)**: פיצוץ חלקיקים, אבק, כוכבים, בועות, שלג, גשם, קונפטי, בוקה, גחליליות
- **סצנות (9)**: שמש ורשת סינת׳ווייב, ברקים, לייזרים, זרקורים, מטריקס, מנהרת טבעות, זוהר צפוני
- **שכבת אפקט (5)**: זוהר, שובל, שובל מתרחב, פעימה, סיבוב
- **שכבה עליונה וטקסט (9)**: וינייטה, VHS, גרעיניות, דליפות אור, פסים קולנועיים, פס התקדמות, טקסט פועם / גליץ׳ / זוהר

כל העיבוד נעשה מקומית בדפדפן. שום קובץ לא נשלח לשרת.
